# PLANET X

Конструктор собственных планет и вселенных: настройка мира, 3D-планета, редактор поверхности, ИИ-создатель жизни, симуляция экосистемы, разумные цивилизации и галерея миров.

Сайт полностью статический: без сборки и без серверной части. Открывается как обычный `index.html` через любой статический сервер.

## Что умеет

- **Главная**: анимированная 3D-планета, популярные миры, быстрые переходы.
- **Создание планеты**: название и идея, тип мира (от астероида до газового гиганта), цвет суши и океана, площадь и глубина океана, рельеф, растительность, цвет неба и плотность атмосферы, облачность и скорость облаков, погода, температура, наклон оси, гравитация, скорость вращения, кольца (цвет, ширина, яркость) и спутники (число, размер). 3D-превью обновляется на лету; планету можно вращать мышью или пальцем и приближать колесом/пинчем.
- **Редактор поверхности**: развёртка планеты с кистью по 10 биомам (леса, горы, океаны, пустыни, вулканы, ледники, болота, кристаллы, пещеры, аномальные зоны). Карта сразу отображается на 3D-шаре.
- **3D-мир по всей планете**: в «Обзоре» планета — единый рельефный шар, а не картинка. Приблизьте её колесом или пинчем, и под атмосферой раскроются горы и острова, лесные массивы по биомам, город разумной цивилизации под куполом и существа из созданных видов. Животные есть только там, где виды уже созданы: у новой планеты их нет. Отдельной вкладки и кнопки «спуститься» больше нет — поверхность живёт прямо на планете. Камера вращается мышью или пальцем, приближается колесом или пинчем.
- **ИИ — создатель жизни**: чат с внешним ИИ через любой OpenAI-совместимый API. ИИ придумывает виды, описывает внешний вид, питание, среду, поведение, защиту, способности, пищевые цепочки и цивилизации. Есть кнопки «Удиви меня», «Создать изображение» (процедурная иллюстрация) и «Добавить на планету».
- **Экосистема**: популяции, пищевые цепочки, адаптация, вымирание и появление подвидов, ручной режим, автосимуляция, катаклизмы и график динамики.
- **Разумные жители**: форма цивилизации (внешность, язык, культура, жилища, города, технологии, транспорт) и генерация ИИ.
- **Мои планеты**: редактирование, публикация, копирование, удаление.
- **Галерея**: поиск, лайки, избранное, профили авторов, посещение миров.
- **Аккаунты**: регистрация и вход, пароль хранится как PBKDF2-хеш с солью.

## ИИ

Сайт не выдаёт заранее заготовленные ответы за работу ИИ. По умолчанию подключён встроенный прокси (`https://shkolny-krug-ai.danya-gubin0813.workers.dev/chat`): ключ не нужен, запрос уходит на сервер прокси, а не из браузера. В настройках (иконка робота в шапке или кнопка «API») можно выбрать своего провайдера:

- провайдера (встроенный прокси, OpenAI, OpenRouter, Groq, DeepSeek, локальный прокси или свой);
- Base URL вида `https://api.example.com/v1`;
- модель;
- API-ключ.

Для OpenAI-совместимых сервисов запрос идёт на `POST {baseUrl}/chat/completions`, ключ хранится только в `localStorage` браузера. Встроенный прокси принимает `{messages}` и возвращает `{reply}`. Без подключения доступен локальный демо-генератор, явно помеченный как не-ИИ.

## Данные

Сайт статический, поэтому база данных заменена хранилищем браузера:

- аккаунты, планеты, виды, цивилизации и настройки — `localStorage` (ключ `planetx.store.v2`);
- очистка данных браузера удаляет миры;
- в разделе «О системе» есть экспорт и импорт резервной копии в JSON;
- галерея общая только в пределах одного браузера. Официальные миры-витрины встроены в сайт.

Для настоящей общей галереи и синхронизации между устройствами нужен бэкенд или BaaS. Архитектура к этому готова: все операции с данными собраны в `assets/js/store.js`.

## Запуск локально

Любой статический сервер из корня проекта, например:

```bash
npx serve .
```

или

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`. Просто открыть `index.html` двойным щелчком нельзя: браузер заблокирует ES-модули и WebCrypto на `file://`.

## Публикация на GitHub Pages

1. Загрузите содержимое проекта в репозиторий (ветка `main`, корень).
2. Settings → Pages → Source: Deploy from a branch → `main`, папка `/ (root)`.
3. Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

Все пути относительные, поэтому сайт работает и в подпапке репозитория.

## Ограничения первой версии

- Нет серверной части: аккаунты и галерея локальные, без синхронизации между устройствами.
- Изображения существ процедурные; отдельная генерация картинок через API не подключена.
- 3D-мир строится из параметров планеты и видов, а не из нарисованной вручную модели: его вид зависит от рельефа, океана, растительности и температуры.
- Публикация в общую галерею для всех посетителей потребует базы данных (например, Supabase) и серверной авторизации.
